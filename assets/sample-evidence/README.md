# Sample Evidence — Assets

This folder is for documentation reference only.

The actual evidence image files served to the frontend are located at:

  frontend/public/sample-evidence/

Vite serves everything in `frontend/public/` directly at the root URL,
so `frontend/public/sample-evidence/sample1.svg` is reachable at:

  http://localhost:5173/sample-evidence/sample1.svg

## Files

| File | Description |
|---|---|
| sample1.svg | Simulated camera feed — Main Entrance, unusual activity detection box |
| sample2.svg | Simulated night-vision feed — North Perimeter, object proximity alert |
| sample3.svg | Simulated overhead feed — Parking Area, unattended object with timer |

## Important

These are entirely SIMULATED images created as SVG graphics.
They are NOT real camera captures.
They are clearly labeled as SIMULATED EVIDENCE within the image itself.
